# Creepy Crawly Kinematics

An interactive, procedurally animated creature built entirely using HTML5 Canvas and vanilla JavaScript. The project demonstrates inverse kinematics to simulate realistic, organic joint movements and joint-stepping constraints as a creature dynamically tracks the cursor across the screen.

## Live Demo
You can interact with the live project here: 
👉 [Live Simulation Link](https://saurav56295.github.io/creepy-crawly-kinematics/)

## Features
* *Procedural Animation:* No pre-baked keyframes; all movements are calculated in real-time.
* *Inverse Kinematics:* Realistic spine-segment bending and organic leg-stepping mechanics.
* *Interactive Tracking:* Smooth mouse cursor trailing with micro-adjustments for responsive acceleration.
